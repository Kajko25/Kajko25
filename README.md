## ⬡ About

Hands-on blockchain builder who learns new chains by shipping real, verified on-chain transactions — not tutorials. Before any mainnet launch, the goal is to already understand the network deeply: mechanisms, gas economics, precompiles, governance, the works.

- 🧪 Tested and built on a wide range of L1/L2 testnets — **Aleo, Fuel, Monad, Polymer, Scroll**, and more
- 🤖 Building **agentic, USDC-native protocols** on **Arc** (Circle's payments-first chain)
- 🔵 Deep into the **Base** ecosystem — Base MCP, ERC-8004 agent identity, x402, B20, Smart Wallet/passkeys, Basenames — exploring it corner by corner because *onchain or it didn't happen*
- 🔷 Full-stack Web3: Solidity/Foundry contracts → TypeScript agents → frontend → deployment
- 🔐 Deliberate about wallet hygiene and on-chain separation between projects
- 📜 Believer in verifying everything independently — if a script says "success," it gets re-checked on-chain
